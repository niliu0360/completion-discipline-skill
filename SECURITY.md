# Security Policy

## Supported version

The current `0.1.x` Public Beta line receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include secrets, private repository contents, personal data, or production credentials in a public issue.

This Skill does not provide automatic enforcement. Review generated `.ai-work/` evidence before committing it because it may contain commands, paths, artifact references, or environment details.
